Project 03 — Phishing Email Detector

Phishing Email Detector

Machine Learning Cybersecurity System — 49,628 Emails · 8 Models Evaluated · Real-Time Gmail Detection

🏆 Best Undergraduate Poster Award, Delaware Data Science Symposium 2025
Best Undergraduate Poster Award — Delaware Data Science Symposium 2025

This research was conducted as part of the DaMAD-ScientistCorps Summer Research Program (May–June 2025) under supervisor Dejene Dedefa, and was presented at the Delaware Data Science Symposium 2025, where it received the Best Undergraduate Poster Award for its rigorous methodology and real-world cybersecurity application.

Project Description

Deployed the top-performing machine learning models and TF-IDF vectorizer as serialized artifacts for efficient inference. Built a desktop application using Python Tkinter and integrated the Gmail API with OAuth authentication to support real-time email retrieval and classification. Users can fetch emails directly from Gmail, select prediction models, execute the full detection pipeline, review results in an interactive table, and visualize confusion matrices and performance metrics through a unified interface.


The project covered the complete machine learning workflow, including feature engineering, model training, evaluation, and application development. Eight machine learning models were evaluated across supervised and unsupervised approaches, with supervised models consistently delivering superior performance. The final result was an interactive desktop application that allows users to fetch emails, compare model predictions, and analyze phishing detection performance.

Feature Engineering

Engineered more than 20 phishing specific features from both email content and metadata, including link analysis, suspicious keyword detection, message length, sender domain verification, public domain identification, domain mismatch detection, and unknown domain classification. Subject and body text were transformed using TF-IDF vectorization using the top 300 features and combined with handcrafted indicators to create a unified feature matrix for model training. Analysis revealed that 99.8% of phishing emails originated from previously unknown sender domains, making domain based features one of the strongest predictors in the system.

Deployment & GUI

Built a desktop application using Python Tkinter and integrated the Gmail API with OAuth authentication to streamline email analysis. Users can retrieve emails from Gmail, select between multiple machine learning models, execute the phishing detection pipeline, review predictions in an interactive table, and visualize confusion matrices and performance metrics. The application provides a practical interface for testing and comparing phishing detection models on real email data.
