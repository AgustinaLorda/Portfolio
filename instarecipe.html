Project 01 — InstaRecipe

InstaRecipe

AI Powered Recipe Discovery Platform and Community for Smarter Meal Planning

Project Description

InstaRecipe is a full stack web application designed to help users make faster and smarter cooking decisions using ingredients they already have at home. The platform combines AI powered recipe recommendations with a community driven recipe database, helping users reduce food waste, save time, and discover new meal ideas. The project was inspired by two common challenges: the large amount of food discarded each year and the time many people spend deciding what to cook.


Users can receive personalized recipe suggestions by entering available ingredients, while registered members gain access to advanced features including recipe search, filtering, recipe uploads, favorites, ratings, reviews, and personalized recommendations. Built with React and Supabase, the platform supports recipe creation, image uploads, draft management, and community engagement through a modern and responsive user experience. My contribution focused on frontend development, including the user interface, authentication flows, responsive layouts, and integration with backend services.

System Architecture

React powers the frontend experience, handling routing, state management, search functionality, and user interactions. Supabase provides authentication, PostgreSQL database storage, image hosting, and backend services. The OpenAI API powers ingredient based recipe recommendations, generating personalized suggestions from ingredients entered by the user. Together, these components create a scalable platform that combines AI assisted meal planning with community generated content.

Key Features

AI recipe recommendations based on available ingredients • Advanced recipe search with filters for cuisine, diet, difficulty, cooking time, and meal type • Recipe uploads with images, ingredients, and step by step instructions • Save draft or publish workflow • User authentication and personalized dashboards • Favorites system with personalized suggestions • Community ratings and reviews • Trending recipes and recipe discovery tools
